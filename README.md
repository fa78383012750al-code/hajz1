# نظام GOO لإدارة المحتوى التعليمي

هذا هو المستودع الموحد للتطبيق. الملف الرئيسي هو `index.html`، وملفات التثبيت كتطبيق ويب تقدمي هي `manifest.json` و`sw.js`، بينما الصور موجودة داخل `icons/`.

## التطوير والنشر

أي تعديل مستقبلي يبدأ من `index.html` أو الملفات المساندة داخل هذا المستودع، ثم يُرفع إلى الفرع `main`. GitHub Pages ينشر النسخة الموجودة في جذر الفرع تلقائياً على الرابط:

`https://fa78383012750al-code.github.io/hajz1/`

لإجبار التطبيق على إظهار تحديث جديد، عدّل قيمة `version` في `version.json`. التطبيق يراجع هذا الملف ويعرض إشعار التحديث عند توفر إصدار أحدث.

## التثبيت على أندرويد

افتح رابط GitHub Pages في Chrome على أندرويد، ثم اختر **إضافة إلى الشاشة الرئيسية** أو **تثبيت التطبيق**. سيعمل التطبيق بواجهة مستقلة عن المتصفح، مع تخزين مؤقت للواجهة والعمل المحلي عند انقطاع الاتصال. مزامنة البيانات مع GitHub تحتاج اتصالاً بالإنترنت ورمز GitHub مضبوطاً من إعدادات التطبيق.

> هذه النسخة PWA قابلة للتثبيت مباشرة. ويمكن لاحقاً تغليف المستودع نفسه داخل APK عبر Trusted Web Activity أو Capacitor دون تغيير مصدر الكود.
